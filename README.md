# Vrinda Store Sales Dashboard - Excel

## Project Overview
Interactive Excel dashboard created to analyze Vrinda Store sales performance, customer demographics, order trends, and sales channels.

The dashboard provides business insights through visual analytics and helps track sales performance across categories, states, age groups, and order channels.

---

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning

---

## Key Insights
- Monthly sales and order trends
- Top-performing states analysis
- Gender-wise sales comparison
- Age group purchasing behavior
- Order channel analysis
- Order status tracking

---

## Features
- Interactive slicers and filters
- Dynamic charts and visualizations
- KPI-driven business analysis
- Customer segmentation insights
